# EsProfe — Roadmap to B1 Launch

## Текущее состояние — 1 сентября 2026

- Архитектурная стабилизация A1 завершена на едином каталоге версии 3.
- Готовы и подключены 35 уроков — от «Алфавита и произношения» до итоговой практики основных неправильных глаголов в presente.
- Маршрут, готовность карточек, загрузка уроков и четыре языка используют единый каталог.
- Временные A1 loaders, активаторы карточек, перехватчик навигации и runtime-подмешивания удалены.
- Перед публикацией обязательна команда `node scripts/validate-a1.mjs`.
- Каждый законченный этап проходит проверку читаемости, понятности навигации, визуальной целостности и мобильного отображения.
- Учебный контент проверяется одновременно с филологической и преподавательской точки зрения.
- Модуль **Ser / estar / hay** состоит из шести последовательных уроков: формы ser, употребление ser, формы estar, употребление estar, hay и смешанное различение.
- Модуль **Presente — правильные глаголы** состоит из пяти уроков: модели -AR, -ER и -IR, их сопоставление и итоговый тренажёр.
- Модуль **Основные неправильные глаголы** состоит из восьми уроков: `tener`, `ir`, `hacer`, `venir`, `querer`, `poder`, `decir` и смешанная практика.
- Следующий модуль: **Возвратные глаголы и распорядок дня**.

## Цель

За 3 недели довести EsProfe до запускаемого учебного уровня **A1–B1**: объяснение → практика → тренажёр → контроль → оценка усвоения → прогресс и слабые места.

Главный принцип: **не переписываем проект с нуля**. Каждая новая функция добавляется в существующую архитектуру и должна оставаться совместимой с уже работающими разделами.

## Что должно быть готово к запуску B1

### 1. Учебная структура
- A1
- A2
- B1
- разделы по темам и грамматике
- последовательность: правило → объяснение → упражнения → тренажёр → контроль
- понятный переход к повторению при слабом результате

### 2. Грамматика B1
- настоящее время и основные модели спряжения
- stem-changing verbs
- основные прошедшие времена
- futuro и условные конструкции базового B1
- imperativo
- pronombres
- ser / estar / hay
- por / para
- preposiciones
- comparativos y superlativos
- reflexivos
- perífrasis verbales
- subjuntivo уровня B1 в необходимых конструкциях
- связки и типичные конструкции B1
- согласование и порядок слов

Для сложных правил допускаются статические наглядные изображения. Интерактивность картинки не является обязательной.

### 3. Практика
Для каждой темы:
- упражнения с выбором ответа
- ввод ответа
- исправление ошибки с объяснением
- упражнения на трансформацию
- заполнение пропусков
- смешанная практика
- итоговый мини-тест

### 4. Тренажёры
- отдельные тренажёры по грамматике
- случайный порядок заданий
- Enter для проверки
- повтор слабых форм/тем
- результат после завершения

### 5. Оценка и прогресс
Ученик всегда должен видеть:
- текущий результат
- процент правильных ответов
- прогресс по теме
- слабые места
- темы, которые нужно повторить
- итоговую оценку раздела
- рекомендацию: продолжать или повторить обучение

### 6. Интерфейс
- ES / EN / RU / UK
- desktop + mobile
- единый стиль всех учебных разделов
- навигация между уровнями и темами

## План на 3 недели

### Неделя 1 — каркас B1
1. Зафиксировать архитектуру учебных разделов.
2. Создать единую модель `lesson → explanation → practice → trainer → assessment`.
3. Завершить навигацию A1/A2/B1.
4. Перенести грамматические темы в структурированные данные.
5. Сделать общий компонент объяснения правила.
6. Сделать общий компонент упражнения.
7. Сделать общий компонент итогового контроля.
8. Проверить текущие тренажёры и не ломать существующую функциональность.

### Неделя 2 — содержание B1
1. Заполнить грамматику A1–B1.
2. Добавить объяснения простым языком.
3. Добавить упражнения к каждой теме.
4. Добавить статические схемы/картинки там, где они реально помогают понять правило.
5. Добавить словарь и тематическую лексику B1.
6. Добавить смешанную практику.

### Неделя 3 — контроль и запуск
1. Завершить систему оценивания.
2. Завершить прогресс ученика.
3. Добавить блок «слабые места / повторить».
4. Проверить все темы и ссылки.
5. Проверить мобильную версию.
6. Проверить 4 языка интерфейса.
7. Провести полный тест A1–B1.
8. Исправить критические ошибки.
9. Подготовить GitHub Pages к запуску.
10. Выпустить стабильную версию B1.

## Правило работы на эти 3 недели

Не тратим время на необязательную визуальную полировку, если она не мешает обучению. Сначала **полный рабочий учебный цикл и содержание B1**, затем косметика.

Статические картинки считаются полноценным учебным материалом и могут просто отображаться внутри соответствующего урока.

## Definition of Done для B1

Тема считается готовой только если ученик может:

1. открыть объяснение;
2. понять правило;
3. выполнить упражнения;
4. потренироваться в тренажёре;
5. пройти контроль;
6. получить результат;
7. увидеть ошибочные места;
8. получить рекомендацию повторить тему или перейти дальше.
