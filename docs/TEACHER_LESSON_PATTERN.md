# Общий каркас короткого урока с преподавателем

Тема, возрастное оформление и лексика задаются данными урока. Футбол — оформление для первого ученика, а не обязательное условие движка. В других темах «таймы» можно назвать практикой, а голы — выполненными заданиями.

Последовательность: цель → слова с изображениями → одна модель → разминка → практика с опорой → самостоятельная практика → разбор ошибок → свои фразы → результат.

Нагрузка: несколько новых слов, одна небольшая модель, 3–4 вида упражнений; без таймера и обязательного прохождения всех дополнительных режимов. Короткая самостоятельная работа; объяснение и разговор с преподавателем могут продлить занятие до 30–40 минут. Один вопрос и его кнопки по возможности занимают один экран, без обрезки и чрезмерного уменьшения текста.

## Основания выбора

- Karpicke & Roediger (2008), The Critical Importance of Retrieval for Learning: самостоятельное воспроизведение слов улучшало отсроченное запоминание сильнее, чем дальнейшее перечитывание. https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf
- Dunlosky et al. (2013), Improving Students’ Learning With Effective Learning Techniques: practice testing и distributed practice получили высокую оценку применимости; простое перечитывание — низкую. https://pubmed.ncbi.nlm.nih.gov/26173288/
- Kim & Webb (2023), Does spaced practice have the same effects on different second language vocabulary learning activities? На отсроченном тесте через две недели интервальная практика помогала и карточкам, и пропускам; универсального превосходства одного из этих форматов не найдено. https://doi.org/10.1111/modl.12879

Исследования не задают единственный лучший интерфейс и не гарантируют одинаковый результат у конкретного ребёнка. Ниже — педагогическое применение результатов, а не доказанный рейтинг кнопок или анимаций.

## Применение в платформе

1. Обзор слова, фото и перевод. Затем **карточки с самопроверкой**, по пять в круге: сначала вспомнить вслух, затем открыть ответ. Оба направления перевода. Испанское слово с артиклем и озвучкой после открытия.
2. «Ещё повторить» возвращает слово после трёх других, если они остались. Не более двух показов одного слова за круг; последние трудные слова отмечаются для следующего круга. Новый круг отдаёт приоритет трудным и ещё не тренировавшимся словам. Это короткое повторение внутри занятия, а не полноценный календарный SRS.
3. **Пары** по четыре: фото + испанское слово → перевод. Фото помогает ориентироваться, но подпись задаёт однозначную задачу, поскольку на фото могут присутствовать разные предметы. Работают нажатия, клавиатура и перетаскивание.
4. Следом **пропуски, короткие самостоятельные ответы, исправление ошибки, свои предложения**. Выбор и пары — опора перед воспроизведением, а не его замена.
5. Повторять материал на следующих занятиях; календарные интервалы в этом выпуске не автоматизированы.

Карточки и пары — необязательная лексическая тренировка, а не новые контрольные задания. Они не добавляют голы и не изменяют результаты отчётов. Круг карточек сохраняется **локально на устройстве, отдельно для гостя и каждого аккаунта**, без облачной синхронизации. Результаты основных заданий сохраняются прежним механизмом. Пары начинаются заново при перезагрузке. Самооценка «Вспомнил» не считается объективно проверенным ответом.

## Расширение

Модуль `clase/vocabulary-practice.js` получает записи с постоянными `id`, словом, переводами и необязательными изображениями; он не знает футбольных слов, голов или ID заданий. Для подключения к следующей теме используется тот же модуль. Сейчас он подключён к словарю «Футбол 2»; первый урок и архивные версии не изменяются.

Завершение: поздравление с визуальным кубком появляется только после выполнения всех обязательных заданий, разбора ошибок по существующим правилам и трёх собственных фраз. Футбольный вариант: «Урок завершён! Ты — чемпион!». Текст задаётся данными темы; самооценка карточек не открывает награду.

Изображения: локальные сжатые WebP, существующее авторство и лицензии. Только короткое CSS-появление ответа, с учётом prefers-reduced-motion. Без тяжёлых библиотек и обязательных видеороликов.
